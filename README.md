# Kuber Estate — website

Static site for kuberestate.co.in. Plain HTML/CSS/JS. Pages are generated by `build.py` from `src/partials/` + the content tables inside `build.py` — edit there, then run `python3 build.py`.

Layout (v3): a short main page — Hero · What we offer (explained, Know more) · Properties (explained + 3 tiles, See all) · About (keystone, Know more) · Contact — plus pages with a Back button and a fade transition: `services.html` (all six services on one page, opening with the five-step infographic; anchors per service), `products/kubercrm.html` (product page, no five-step), `properties.html` (all listings), `about.html` (keystone → difference → vision → founders → CRM). On the main page, What we offer = two tiles (Services / Products) with icon links straight to the details. Floating glass dock for navigation. `index.v1.html` is the old long-scroll version, kept for reference.

## Files
- `index.html`, `services.html`, `products/kubercrm.html`, `properties.html`, `about.html` — generated output (do not hand-edit; change `build.py` / `src/partials/`)
- `styles.css` — design tokens (brutalist-editorial: warm gray canvas, Anton display type, white rounded cards, black blocks, mint/yellow accents) + layout
- `script.js` — mobile nav, reveal-on-scroll, hero video control, pinned keystone story (bridge → stones → keystone lifts out), pinned process deck, enquiry form → WhatsApp (+ Netlify Forms)
- `assets/` — icons; put your own photos here (hero, properties, founders, KuberCRM screenshot)
- `brand/` — logo exploration (rounds 1–9). FINAL = the Keystone with R: `brand/keystone-R.svg`; site copies in `assets/logo-keystone.svg`, `assets/icon.svg` (favicon/touch icon), `assets/og.png` (share image)

## Accessibility
Text colours use `--ink-muted` (dark surfaces flip it via `--ink-muted-dark`); every page passes a WCAG AA contrast check (4.5:1 body / 3:1 large). Keep using the tokens rather than raw greys.

## Enquiry form
Submitting opens WhatsApp with the details pre-filled. When hosted on Netlify, the same
submission is also captured by Netlify Forms (set the notification email in Netlify → Forms).
